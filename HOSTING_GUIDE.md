# Cara Host Privacy Policy di GitHub Pages

## Langkah 1: Buat Repository di GitHub

1. Buka browser dan pergi ke: **https://github.com/new**
2. Isi form:
   - **Repository name:** `privacy-policy`
   - **Description:** "Privacy Policy for Travel Booking App"
   - Pilih **Public** ✅
   - ✅ Centang "Add a README file"
3. Klik **Create repository**

## Langkah 2: Upload File Privacy Policy

1. Di halaman repository yang baru dibuat, klik **Add file** → **Upload files**
2. Drag & drop file ini: `privacy_policy.html`
   (File ada di: `/Users/fitroaidil/travel_booking_app/privacy_policy.html`)
3. Di bagian bawah, isi commit message: "Add privacy policy"
4. Klik **Commit changes**

## Langkah 3: Aktifkan GitHub Pages

1. Di repository, klik tab **Settings** (pojok kanan atas)
2. Scroll ke bawah atau cari menu **Pages** di sidebar kiri
3. Di bagian **Source**:
   - Branch: Pilih **main** (atau **master**)
   - Folder: Pilih **/ (root)**
4. Klik **Save**
5. Tunggu 1-2 menit
6. Refresh halaman, akan muncul notifikasi:
   ```
   Your site is live at https://[username].github.io/privacy-policy/
   ```

## Langkah 4: Dapatkan URL Privacy Policy

URL lengkap Privacy Policy Anda:
```
https://[username-github].github.io/privacy-policy/privacy_policy.html
```

**Contoh:**
- Jika username GitHub Anda: `fitroaidil`
- URL Privacy Policy: `https://fitroaidil.github.io/privacy-policy/privacy_policy.html`

## Langkah 5: Test URL

1. Buka URL di browser
2. Pastikan Privacy Policy tampil dengan benar
3. Cek apakah kontak info sudah benar:

## Langkah 6: Simpan URL untuk Play Store

Copy URL lengkap Privacy Policy Anda dan simpan di notepad.
URL ini akan dipakai saat submit aplikasi ke Google Play Store.
